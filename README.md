# tg-bot-design — маркетплейс дизайн-кода Telegram-ботов

Плагин со скиллом **telegram-bot-design** — единый дизайн-код интерфейса наших
Telegram-ботов (aiogram 3.x, HTML) + обязательная проверка соответствия перед
`commit`/`push`.

Дизайн-код покрывает:
- кастом-эмодзи `tgiosicons` на кнопках и заголовках (только при Premium владельца);
- текст: жирный статик / моно переменные / цитаты-пояснения / заголовки разделов;
- таблицы (rich-сообщения) для статистики и сводок;
- цвет только на важные кнопки (синий = старт, зелёный = приход, красный = стоп);
- анти-флуд: затирание старых сообщений, edit на месте;
- чек-лист проверки соответствия перед коммитом.

## Подключить «откуда угодно»

Публичный репозиторий: https://github.com/bacubelo24-sudo/telegram_claude

В любом проекте/машине подключить маркетплейс и установить плагин:
```
/plugin marketplace add bacubelo24-sudo/telegram_claude
/plugin install telegram-bot-design@tg-bot-design
```
Имя маркетплейса берётся из `.claude-plugin/marketplace.json` (`tg-bot-design`),
поэтому установка идёт как `telegram-bot-design@tg-bot-design`.

Если `marketplace add` по короткому пути падает на SSH host key — используйте HTTPS-URL:
```
/plugin marketplace add https://github.com/bacubelo24-sudo/telegram_claude.git
```

## Локально (эта машина, без маркетплейса)

Скилл также установлен как персональный в `~/.claude/skills/telegram-bot-design/` —
доступен во всех проектах на этой машине сразу, без подключения маркетплейса.

## Использование

Скилл подхватывается, когда создаёшь/правишь интерфейс Telegram-бота или перед
коммитом таких изменений. Можно вызвать явно: `/telegram-bot-design`.
